# Launch plan

This project is strongest when it is positioned as a clean, useful, public-source local utility rather than a shady scraping service.

## Positioning

- Public-source and transparent
- Local-first and easy to run
- Anonymous by default
- Built for practical analysis, not fake engagement tricks

## Messaging angle

"A lightweight local tool for auditing public Instagram follower and following lists into clean Excel reports."

## Why it is shareable

- solves a real pain point
- easy to demo in one screen capture
- no setup friction for developers
- very easy to explain in a sentence
- strong public-source story

## What to emphasize in posts

- no login required
- local-only workflow
- export to Excel
- compare mode
- public-source code

## What not to do

- avoid claims of guaranteed follower growth
- avoid login-required flows
- avoid misleading or spammy marketing language
- avoid pretending it is a hosted service

## Launch checklist

1. Make the README clear and product-like
2. Keep the app simple to run locally
3. Publish a clean repository with docs and tests
4. Share screenshots of the app and output workbook
5. Document one realistic use case per post
